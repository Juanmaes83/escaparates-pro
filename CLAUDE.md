# ESCAPARATES PRO — CLAUDE OPERATING CONTRACT

Claude Code must treat the repository-level Safe Autonomous Engineering skill as a mandatory operating contract for **all work in Escaparates Pro**.

## Read first

Before modifying any code, docs, assets, tests, QA, infrastructure, module, donor integration or autonomous workstream, read:

`/.claude/skills/safe-autonomous-engineering/SKILL.md`

Also read the relevant module-specific roadmap, protected baseline, decision log, contracts and lessons before acting.

## Global, not Museum-specific

Safe Autonomous Engineering is a repository-wide Escaparates Pro skill. Museum / Immersive Worlds inherits it; it must not maintain a second full duplicate copy.

Module-specific documents should add only local product rules and reference the global skill.

## Claude execution rule

If the current mandate contains additional authorized work after an internal checkpoint, continue autonomously through that checkpoint. Do not stop merely because a subphase or QA checkpoint passed.

Only stop at the defined human gate or for a stop condition described by the global skill.

## Absolute merge rule

Claude may clone, create isolated branches/worktrees, experiment inside isolated copies, commit, push isolated work and prepare PRs when useful.

Claude must never merge, promote to canonical/stable, delete canonical sources, or destructively consolidate without explicit Juanma approval.
