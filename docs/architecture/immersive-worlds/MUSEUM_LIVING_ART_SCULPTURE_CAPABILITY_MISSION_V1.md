Can these behaviors later become semantic authoring choices rather than raw engine parameters?

## EXHIBITION SCALE
Can different works combine different capabilities while sharing one Museum orchestration contract?

## PRODUCTION SCALE
Can the same capabilities produce runtime experiences plus teasers, key visuals, educational views, video or campaign material?

These questions guide discovery. They do not define fixed deliverables.
